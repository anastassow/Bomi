PARTLY IMPLEMENTED
==================

What works only in part, and what is missing.
Delete a section when it is done.


UNARY OPERATORS
  done      - + ~ ++ -- (prefix and postfix): parser, AST, IR, ARM64
  missing   ! & *  parse, but lowering stops: "Unsupported unary operator"

    !x    needs comparisons      icmp eq x, 0  then  zext    (ARM64: cmp, cset)
    &x    needs pointer types    the result is x's slot (its alloca), no instruction
    *p    needs pointer types    load from (or store to) the address in p

  later     ++ and -- on a pointer move one element (getelementptr), not 1
  known     -2147483648 fails: the lexer reads 2147483648 first, which is too big

  Order: comparisons (with !), then types and the analysis pass, then & and *.


SIZEOF AND CASTS
  Parse, then stop: "sizeof not supported yet", "casts not supported yet".
  Need real types first.


POINTER AND ARRAY DECLARATIONS
  int *p;  int a[3];  become plain  int p;  int a;  (the * and [3] are lost)


DECLARATIONS
  One variable per declaration: int x, y; is an error.
  Declarations must come before statements in a block (C89).
  Global variables and prototypes are dropped.
  Types other than int crash.


FUNCTIONS
  Parameters are not kept: using one gives "Use of undeclared variable".
  A call becomes just the name: f() is var f.
  void is never set: the function comes out as int.
  A function with no return type disappears.


CONSTANTS
  010 is read as 10 (should be 8).
  'a' and 2.5 get the last value the lexer read.


COMMENTS
  /* */ works, but its text is printed to stdout.
  // is a syntax error.
  An unclosed /* is accepted.
